# Backup Role

## Status: ✅ Implemented

This role provides automated backup functionality for HashiCorp Consul, Nomad, and Vault clusters.

## Features

- ✅ **Consul Snapshots**: Create and compress Consul cluster snapshots
- ✅ **Nomad Snapshots**: Create and compress Nomad cluster snapshots
- ✅ **Vault Snapshots**: Create and compress Vault cluster snapshots (requires unsealed Vault)
- ✅ **Automatic Compression**: Optional gzip compression for space efficiency
- ✅ **Retention Policy**: Automatic cleanup of old backups
- ✅ **Timestamped Backups**: ISO 8601 formatted timestamps for easy identification

## Requirements

- Consul/Nomad/Vault CLI tools must be installed
- Appropriate ACL tokens for snapshot operations
- Sufficient disk space in backup directory
- `community.general` collection (for archive module)

## Variables

### Core Settings

| Variable | Default | Description |
|----------|---------|-------------|
| `backup_enabled` | `false` | Master enable/disable switch |
| `backup_dir` | `{{ playbook_dir }}/backups` | Directory for backup storage |
| `backup_timestamp_format` | `%Y%m%d_%H%M%S` | Timestamp format for backups |

### Consul Backup

| Variable | Default | Description |
|----------|---------|-------------|
| `backup_consul_enabled` | `true` | Enable Consul backups |
| `backup_consul_snapshot` | `true` | Create Consul snapshots |
| `backup_consul_acl_tokens` | `false` | Backup ACL tokens (sensitive!) |

### Nomad Backup

| Variable | Default | Description |
|----------|---------|-------------|
| `backup_nomad_enabled` | `true` | Enable Nomad backups |
| `backup_nomad_snapshot` | `true` | Create Nomad snapshots |

### Vault Backup

| Variable | Default | Description |
|----------|---------|-------------|
| `backup_vault_enabled` | `false` | Enable Vault backups |
| `backup_vault_snapshot` | `false` | Create Vault snapshots |

⚠️ **Note**: Vault must be unsealed for snapshots to work.

### Retention

| Variable | Default | Description |
|----------|---------|-------------|
| `backup_keep_days` | `7` | Number of days to keep backups |
| `backup_compression` | `true` | Compress backups with gzip |

## Usage

### Basic Backup

```bash
# Run backup for all services
ansible-playbook -i inventories/prod/hosts.yml site.yml --tags backup
```

### Enable Backups

```yaml
# group_vars/all.yml or host_vars
backup_enabled: true
backup_consul_enabled: true
backup_nomad_enabled: true
backup_vault_enabled: false  # Requires unsealed Vault
```

### Custom Backup Directory

```yaml
backup_dir: /mnt/backups/ncv
```

### Adjust Retention

```yaml
backup_keep_days: 30  # Keep backups for 30 days
```

## Backup Files

Backups are stored with the following naming convention:

```
backups/
├── consul_20251229_120000.snap.gz
├── nomad_20251229_120000.snap.gz
└── vault_20251229_120000.snap.gz
```

## Restoration

### Consul Restore

```bash
# Decompress if needed
gunzip consul_20251229_120000.snap.gz

# Restore snapshot
consul snapshot restore consul_20251229_120000.snap
```

### Nomad Restore

```bash
# Decompress if needed
gunzip nomad_20251229_120000.snap.gz

# Restore snapshot
nomad operator snapshot restore nomad_20251229_120000.snap
```

### Vault Restore

```bash
# Decompress if needed
gunzip vault_20251229_120000.snap.gz

# Restore snapshot (Vault must be unsealed)
vault operator raft snapshot restore vault_20251229_120000.snap
```

## Automation

### Scheduled Backups with Cron

```yaml
# Add to your playbook
- name: Schedule daily backups
  ansible.builtin.cron:
    name: "NCV daily backup"
    minute: "0"
    hour: "2"
    job: "cd /path/to/ncv && ansible-playbook site.yml --tags backup"
    user: automation
```

### CI/CD Integration

```yaml
# .github/workflows/backup.yml
name: Scheduled Backup
on:
  schedule:
    - cron: '0 2 * * *'  # Daily at 2 AM
  workflow_dispatch:

jobs:
  backup:
    runs-on: self-hosted
    steps:
      - uses: actions/checkout@v4
      - name: Run backup
        run: ansible-playbook site.yml --tags backup
```

## Security Considerations

⚠️ **Important Security Notes**:

1. **Backup Directory Permissions**: Default mode is `0700` (owner only)
2. **ACL Tokens**: Set `backup_consul_acl_tokens: false` unless absolutely necessary
3. **Encryption**: Consider encrypting backup directory at rest
4. **Off-site Storage**: Copy backups to remote storage for disaster recovery
5. **Access Control**: Restrict access to backup directory
6. **Sensitive Data**: Backups contain cluster state - treat as sensitive!

### Example: Encrypt Backups

```bash
# Encrypt backup with GPG
gpg --symmetric --cipher-algo AES256 consul_backup.snap.gz

# Decrypt when needed
gpg --decrypt consul_backup.snap.gz.gpg > consul_backup.snap.gz
```

## Troubleshooting

### "Permission denied" Error

**Solution**: Ensure the user has appropriate ACL permissions:

```bash
# Consul
consul acl policy create -name backup -rules 'operator = "read"'

# Nomad  
nomad acl policy apply -description "Backup policy" backup backup-policy.hcl
```

### "Vault is sealed" Error

**Solution**: Unseal Vault before taking snapshots, or disable Vault backups.

### Disk Space Issues

**Solution**: 
- Increase `backup_keep_days` retention
- Enable `backup_compression: true`
- Use external storage

## Best Practices

1. ✅ **Test Restores Regularly**: Verify backups can be restored
2. ✅ **Off-site Copies**: Store backups in multiple locations
3. ✅ **Automate**: Schedule regular backups via cron or CI/CD
4. ✅ **Monitor**: Alert on backup failures
5. ✅ **Document**: Keep restoration procedures documented
6. ✅ **Encrypt**: Encrypt sensitive backups at rest
7. ✅ **Version**: Keep multiple backup versions
