# NCV Ansible

Production-ready Ansible playbooks and roles to install and configure a Nomad + Consul + Vault cluster on bare metal, VMs, or cloud instances.

## Supported OS

- Ubuntu 22.04, 24.04
- Oracle Linux
- AlmaLinux

## Requirements

- Ansible 2.14+
- Collections: `community.crypto`, `community.general`, `ansible.posix`

Install collections:

```bash
ansible-galaxy collection install -r collections/requirements.yml
```

## Quick start

1) Copy and edit the inventory:

```bash
cp -R inventories/example inventories/my-env
```

2) Update `inventories/my-env/hosts.yml` with your hosts, users, and groups.

3) Review variables in `group_vars/all.yml` (TLS, ACLs, storage).

4) Run:

```bash
ansible-playbook -i inventories/my-env/hosts.yml site.yml
```

## TLS/PKI

By default the `pki` role can generate a local CA and per-host certificates into `pki/` (gitignored). For production, disable local generation and provide external certs:

- Set `pki_generate: false`
- Set `*_tls_source: files` and provide `*_tls_ca_src`, `*_tls_cert_src`, `*_tls_key_src`

## Consul ACLs
ACLs are enabled by default. After bootstrap, you must run Consul ACL bootstrap and distribute tokens. Set:
- `consul_acl_agent_token`
- `consul_acl_default_token`
- `consul_acl_replication_token`

## Cloud auto-join
Static `retry_join` is default. For cloud auto-join, set:
```yaml
consul_retry_join_cloud_enabled: true
consul_retry_join_cloud:
  - "provider=aws tag_key=consul tag_value=server"
```

Nomad uses similar variables:
```yaml
nomad_retry_join_cloud_enabled: true
nomad_retry_join_cloud:
  - "provider=gce project_name=my-project tag_value=nomad-server"
```

Best practice: keep cloud-specific auto-join values in the inventory scope, for example
`inventories/aws/group_vars/all.yml` and `inventories/gcp/group_vars/all.yml`.

## Vault storage and auto-unseal
- Default storage: `consul`
- Alternative: `raft`
- Auto-unseal: set `vault_seal_type` to `awskms`, `gcpckms`, or `transit` and provide `vault_seal_config`.
- When Consul TLS is enabled, Vault will use HTTPS and Consul TLS files by default.

## Firewall
Optional firewall role with `ufw`/`firewalld`:
```yaml
firewall_enabled: true
firewall_allow_cidrs:
  - 10.10.0.0/16
```

## Load balancer plan
Optional role renders a plan file under `docs/lb-plans/` with recommended listeners and targets. See `docs/load_balancers.md`.

## Nomad jobs
Place job files under `jobs/` and enable:
```yaml
nomad_jobs_enabled: true
```

Job catalog and examples live in `jobs/README.md`.
