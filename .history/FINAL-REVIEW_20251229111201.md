#### 3. ✅ Missing Consul HTTPS Port (8501) - FIXED
**Problem**: Firewall defaults included port 8500 (HTTP) but not 8501 (HTTPS), even though Consul HTTP is disabled by default.

**Solution**:
```yaml
# roles/firewall/defaults/main.yml
firewall_ports:
  - {port: 8500, proto: tcp}  # Consul HTTP (disabled by default)
  - {port: 8501, proto: tcp}  # Consul HTTPS ← ADDED
  - {port: 8502, proto: tcp}  # Consul gRPC
```

**Impact**: Consul HTTPS traffic now properly allowed through firewall.
