### 📌 MEDIUM Priority Issues

#### 1. Missing variable `consul_http_disable` in group_vars/all.yml

**Проблема**: Переменная `consul_http_disable` используется в template, но не определена в `group_vars/all.yml`.

**Файлы**:
- [roles/consul/defaults/main.yml](roles/consul/defaults/main.yml#L27) - `consul_http_disable: true`
- [roles/consul/templates/consul.hcl.j2](roles/consul/templates/consul.hcl.j2#L10) - использует переменную
- [group_vars/all.yml](group_vars/all.yml) - переменная отсутствует

**Влияние**: 
- Переменная берется из role defaults, но не переопределяется в group_vars
- Может вызвать путаницу при конфигурации

**Решение**:
```yaml
# group_vars/all.yml (добавить после consul_https_port)
consul_http_disable: true  # Disable HTTP when TLS is enabled
```

**Обоснование**: Консистентность - все важные Consul параметры должны быть в group_vars/all.yml.

#### 2. Inconsistent variable naming for Vault Consul token

**Проблема**: Несоответствие имен переменных для Vault Consul token.

**Файлы**:
- [group_vars/all.yml](group_vars/all.yml#L113): `vault_consul_token: "{{ vault_vault_consul_token | default('') }}"`
- [roles/vault/defaults/main.yml](roles/vault/defaults/main.yml#L31): `vault_consul_token: ""`

**Влияние**: 
- Двойное `vault_` в имени (`vault_vault_consul_token`) выглядит избыточно
- Может вызвать путаницу

**Решение**:
Option A (рекомендуется): Переименовать в group_vars/all/vault.yml.example:
```yaml
# Было:
vault_vault_consul_token: ""

# Стало:
vault_consul_token_secret: ""
```

И в group_vars/all.yml:
```yaml
# Было:
vault_consul_token: "{{ vault_vault_consul_token | default('') }}"

# Стало:
vault_consul_token: "{{ vault_consul_token_secret | default('') }}"
```

**Обоснование**: Чище и понятнее. Суффикс `_secret` явно указывает на encrypted variable.

#### 4. Missing validation for `firewall_zone` variable

**Проблема**: Переменная `firewall_zone` используется без валидации корректных значений.

**Файл**: [roles/firewall/defaults/main.yml](roles/firewall/defaults/main.yml#L3)

```yaml
firewall_zone: public  # Нет валидации
```

**Решение**: Добавить в [roles/firewall/tasks/main.yml](roles/firewall/tasks/main.yml):
```yaml
- name: Validate firewall zone
  ansible.builtin.assert:
    that:
      - firewall_zone in ['public', 'internal', 'external', 'dmz', 'work', 'home', 'trusted', 'drop', 'block']
    fail_msg: "Invalid firewall_zone '{{ firewall_zone }}'. Must be a valid firewalld zone."
  when: 
    - firewall_enabled
    - firewall_backend_effective == 'firewalld'
```

**Обоснование**: Предотвращает ошибки конфигурации firewalld.

#### 7. Missing PKI role

**Проблема**: В структуре проекта отсутствует роль `pki`, хотя она упоминается в:
- [site.yml](site.yml#L36): `role: pki`

**Решение**: Определить статус PKI:
- Если используется внешний PKI - документировать это
- Если нужна роль - создать или восстановить
- Если не используется - удалить ссылки из site.yml

#### 8. Backup role - Vault snapshot requires unseal

**Проблема**: В [roles/backup/tasks/main.yml](roles/backup/tasks/main.yml#L57) Vault snapshot создается, но в коде нет проверки, что Vault unsealed.

**Влияние**: 
- Backup упадет если Vault sealed
- Нет предупреждения для пользователя

**Решение**: Добавить проверку:
```yaml
- name: Check if Vault is unsealed
  ansible.builtin.uri:
    url: "{{ vault_api_addr }}/v1/sys/health"
    validate_certs: false
    status_code: [200]
  register: vault_health
  failed_when: false
  when: backup_enabled and backup_vault_enabled

- name: Warn if Vault is sealed
  ansible.builtin.debug:
    msg: "WARNING: Vault is sealed. Skipping Vault backup."
  when:
    - backup_enabled
    - backup_vault_enabled
    - vault_health.status != 200
```

#### 9. No log rotation configuration for services

**Проблема**: Consul, Nomad, Vault логи не ротируются автоматически.

**Влияние**: Диски могут заполниться логами в production.

**Решение**: Создать task для настройки logrotate:
```yaml
# roles/common/tasks/logrotate.yml
- name: Configure logrotate for HashiCorp services
  ansible.builtin.copy:
    dest: /etc/logrotate.d/hashicorp
    content: |
      /var/log/consul/*.log {
        daily
        rotate 14
        compress
        delaycompress
        missingok
        notifempty
        create 0644 consul consul
      }
      /var/log/nomad/*.log {
        daily
        rotate 14
        compress
        delaycompress
        missingok
        notifempty
        create 0644 nomad nomad
      }
      /var/log/vault/*.log {
        daily
        rotate 14
        compress
        delaycompress
        missingok
        notifempty
        create 0644 vault vault
      }
    mode: "0644"
  become: true
```

#### 10. Missing rate limiting in Nomad job deployment

**Проблема**: В [roles/nomad_jobs/tasks/main.yml](roles/nomad_jobs/tasks/main.yml) нет ограничения на параллельное развертывание jobs.

**Влияние**: 
- Можно случайно задеплоить 50+ jobs одновременно
- Может перегрузить кластер

**Решение**: Добавить throttle:
```yaml
- name: Run Nomad jobs
  ansible.builtin.command: >-
    nomad job run {{ item.path | basename }}
  environment: "{{ nomad_jobs_env }}"
  loop: "{{ nomad_jobs_files.files }}"
  throttle: 3  # Максимум 3 job одновременно
```
