### 7. ✅ Added Vault unsealed check in backup
**File**: [roles/backup/tasks/main.yml](roles/backup/tasks/main.yml)
```yaml
- name: Check if Vault is unsealed
  ansible.builtin.uri:
    url: "{{ vault_api_addr }}/v1/sys/health"
    validate_certs: false
    status_code: [200]
  register: vault_health
  failed_when: false

- name: Warn if Vault is sealed
  ansible.builtin.debug:
    msg: "WARNING: Vault is sealed. Skipping Vault backup."
  when: vault_health.status | default(0) != 200
```
**Impact**: Graceful handling когда Vault sealed, предотвращает неудачные backups.
